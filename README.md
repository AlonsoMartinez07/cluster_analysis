# GENE electron cluster analysis

Used to analyze clusters from different unsupervised non k-means clustering algorithms
Structured log of clustering experiments on **CAE latent + physics** (20D: 13 AE + 7 `.nc` scalars)

## Repository layout

```
cluster_analysis/
  README.md                 # this file
  config.yaml               # paths + hyperparameters (edit for your machine)
  run_sync_results.cmd      # copy existing DCEC outputs here (fast)
  run_clustering.cmd        # re-run methods with logs (slow)
  src/
    run_clustering_logged.py
    sync_existing_results.py
    paths_config.py
  analysis/
    outputs/                # figures, CSVs, sweep galleries (by method)
    manifest.json           # generated by sync
  logs/
    YYYYMMDD-<method>/        # stdout logs per run
  data/
    processed/              # shared tables (assignments, scores)
```

**Implementation code** still lives under `D:/GENE_simulation_AI/DCEC/torch_DCEC_RGB/` (autoencoder, clustering scripts). This repo **orchestrates** those scripts and stores **results + logs**.

## Feature space (all clustering methods)

| Component | Source |
|-----------|--------|
| 13D latent | `CAE_bn3_AE_lat13.pt` on RGB difference images |
| 7D physics | `temp_e,dens_e,omn_e,omt_e,beta,rhostar,x0` from matching `.nc` |
| Scaling | StandardScaler on physics, then on full 20D vector |

## Methods tried (what / why)

| Method | Script (DCEC) | Role | Typical K |
|--------|---------------|------|-----------|
| **GMM + BIC** | `cluster_ae_physics_gmm.py --method gmm` | Probabilistic; pick k by BIC | **12** (BIC min) |
| **Agglomerative (Ward)** | `cluster_ae_physics_gmm.py --method agglomerative` | Hierarchical; silhouette vs k | **8** (silhouette max) |
| **HDBSCAN** | `cluster_ae_physics_hdbscan.py` | Density; noise label `-1` | ~51 clusters + ~47% noise (default) |
| **DeepDPM** | `prepare_deepdpm_data.py` + `DeepDPM/DeepDPM.py` | Nonparametric deep clustering on 20D | **init_k=12**, final K inferred |
| **Robustness** | `run_umap_pacmap_robustness_sweep.py` | ~24 **combined** UMAP+PaCMAP panels + kNN | visualization only |
| **3D score view** | `visualize_cluster_score_anomaly_3d.py` | Cluster × index × Maxwellian (Plotly) | per assignment CSV |
| **Maxwellian score** | `score_v7_Cursor.py` (TPED) | Physics-based scalar for coloring / 3D z-axis | sensitivity **500** |

We **do not** store separate-only UMAP and separate-only PaCMAP PNGs here; the robustness sweep uses **side-by-side combined** panels only.


## Current findings

- **GMM (k=12)** and **agglomerative (k=8)** disagree on partition count; compare assignments before trusting either.
- **HDBSCAN** at default settings is **over-fragmented** for this dataset; treat as exploratory unless `min_cluster_size` is retuned.
- **UMAP/PaCMAP robustness**: look for **recurring** off-bulk groups (e.g. cluster 9, partial 3+11) across seeds — not for choosing k alone.
- **kNN gap plots** (in each sweep folder): check intra- vs non-cluster distance separation per label.
- **Next science focus** (PM): whether clusters are **real modes** and **why** simulations split — tie clusters to physics parameters and Maxwellian scores.
