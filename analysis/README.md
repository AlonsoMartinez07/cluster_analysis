# Analysis outputs

Each subfolder under `outputs/` holds **final artifacts** for one method (not duplicate UMAP-only / PaCMAP-only files).

| Folder | Contents |
|--------|----------|
| `gmm_bic/` | BIC & silhouette vs k, `cluster_assignments.csv` (k=12) |
| `agglomerative_ward/` | Silhouette vs k, `cluster_assignments_agglomerative_ward_k8.csv` |
| `hdbscan/` | Assignments, cluster sizes, single UMAP diagnostic |
| `deepdpm_combined20d/` | DeepDPM 20D assignments + exports |
| `robustness_deepdpm/` | UMAP+PaCMAP robustness for DeepDPM labels |
| `embed_clusters_*` | UMAP\|PaCMAP colored by cluster (per method) |
| `embed_maxwellian_combined/` | UMAP\|PaCMAP colored by Maxwellianity (v7, sens=500) |
| `tda_exploratory/` | `embed_persistence_combined.png`, Mapper HTML, `filtration_blob_demo_combined_pacmap_slider.html` |
| `robustness_gmm/` | `sweep_*/index.html` + kNN PNGs (GMM labels) |
| `robustness_agglomerative_k8/` | same for agglomerative k=8 |
| `robustness_hdbscan/` | same for HDBSCAN labels |
| `score3d_*` | Static PNG + **interactive HTML** (Maxwellian vs cluster) |

`manifest.json` is generated by `src/sync_existing_results.py`.

### Cluster browser (interactive)

```cmd
..\run_browse_cluster.cmd
```

Writes `cluster_browser/<method>/cluster_<id>/gallery.html` plus `rgb/` and `f_sim/` images for that cluster only.
